## 💡 About the Project

VendorAI is an AI-powered GST and business management platform
designed for MSMEs. It automates invoice processing, GST analysis,
ITC identification, fraud detection, forecasting, and business
decision-making using AI.

---

## ✨ Key Features

- 📄 AI-powered Invoice OCR
- 🧾 Automated GST Processing
- 💰 ITC Identification & Optimization
- 🔍 Fraud & Anomaly Detection
- 📊 Business Analytics
- 📈 Sales & Cash-Flow Forecasting
- 🤖 AI Business Copilot
- 💡 Smart Business Recommendations
- 📦 Inventory Insights
- 🔔 Compliance Alerts

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS  
**Backend:** Node.js / FastAPI  
**Database:** PostgreSQL  
**AI/ML:** Python, Scikit-learn, PyTorch  
**OCR:** Tesseract / PaddleOCR  
**LLM:** Llama / GPT  
**RAG:** Vector Database + Embeddings  
**Deployment:** Docker
